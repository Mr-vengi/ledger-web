# Tamil Font Setup for PDF Generation

This guide explains how to enable pure Tamil text rendering in PDFs generated by the cloud function.

## Current Status

✅ **Tamil Support is Enabled**
- The code now renders **pure Tamil text** (no Tanglish conversion)
- Automatically detects Tamil text and uses Tamil fonts
- Falls back to Helvetica if Tamil fonts are not available
- **Fonts are already in assets directory**: `ledger/assets/icon/fonts/`

## How It Works

1. **Automatic Detection**: The code detects Tamil Unicode characters (U+0B80 to U+0BFF)
2. **Font Selection**: If Tamil is detected, it uses the 'Tamil' font family
3. **Font Loading**: Automatically checks both:
   - `functions/fonts/` (for deployment)
   - `assets/icon/fonts/` (for local development)
4. **Fallback**: If Tamil fonts are not found, it uses Helvetica (may not render Tamil correctly)

## Setup Instructions

### ✅ Fonts Already Available

Your Tamil fonts are already in:
- `ledger/assets/icon/fonts/NotoSansTamil-Regular.ttf`
- `ledger/assets/icon/fonts/NotoSansTamil-Bold.ttf`

### Automatic Font Copying

The code automatically:
1. Checks `functions/fonts/` first (for deployment)
2. Falls back to `assets/icon/fonts/` (for local development)

### For Deployment

Before deploying, copy fonts to functions directory:

**Option 1: Automatic (Recommended)**
```bash
cd ledger/functions
npm run copy-fonts
```

**Option 2: Manual**
```bash
cd ledger/functions
mkdir -p fonts
cp ../assets/icon/fonts/NotoSansTamil-*.ttf fonts/
```

**Option 3: Automatic on Deploy**
The `predeploy` script automatically copies fonts before deployment:
```bash
firebase deploy --only functions
```

### Deploy

```bash
cd ledger/functions
firebase deploy --only functions
```

## Testing

After deployment, test with Tamil text:
- Shop names in Tamil
- Customer names in Tamil
- Transaction descriptions in Tamil

The PDF should display pure Tamil characters correctly.

## Troubleshooting

### Tamil text not rendering correctly

1. **Check font files exist**: Verify files are in `functions/fonts/` directory
2. **Check file names**: Ensure file names match the paths in code
3. **Check font format**: Must be TTF (TrueType Font) format
4. **Check deployment**: Ensure fonts are included in deployment (they should be automatically)

### Font files too large

If font files are very large, consider:
- Using subset fonts (only Tamil characters)
- Compressing fonts
- Using web fonts and downloading on-demand

## Notes

- The code automatically detects Tamil and switches fonts
- English text continues to use Helvetica
- Mixed English/Tamil text will use Tamil font (to ensure Tamil renders correctly)
- Font files are loaded at function initialization for performance
